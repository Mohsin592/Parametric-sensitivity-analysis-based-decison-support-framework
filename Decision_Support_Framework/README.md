# Decision Support Framework

This folder contains the computational code and input datasets used for the PROMETHEE-II-based Decision Support Framework (DSF) developed in this study.

The framework evaluates and ranks building design alternatives based on embodied global warming potential, life-cycle global warming potential, and GRIHA-2019 performance.

## Files

- `PROMETHEE_II_DSF.py` – Python code used for entropy-based weighting and PROMETHEE-II analysis.
- `Decision_Support_Data.xlsx` – Input dataset containing the 960 building design alternatives and their corresponding performance values.

## Methodology

The Decision Support Framework combines entropy-based criterion weighting with PROMETHEE-II to evaluate and rank alternative building configurations.

The analysis considers:
- Embodied Global Warming Potential
- Life-Cycle Global Warming Potential
- GRIHA-2019 Score

The framework evaluates 960 building design alternatives generated from different wall-envelope configurations, rooftop PV coverage scenarios, cement alternatives, and structural steel types.
